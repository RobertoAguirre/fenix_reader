# 📁 Carpeta de Imágenes

## 🎨 Logo del Fénix

**Coloca aquí el logo original que te pasaron.**

### Nombre del archivo:
```
fenix_logo.png
```

### Ubicación exacta:
```
fenix_reader/
  └── assets/
      └── images/
          └── fenix_logo.png  ← Coloca el logo aquí
```

### Formatos soportados:
- ✅ PNG (recomendado)
- ✅ JPG/JPEG
- ✅ SVG (si es necesario, se puede ajustar)

### Tamaño recomendado:
- **Mínimo:** 512x512 px
- **Recomendado:** 1024x1024 px o superior
- **Formato:** PNG con fondo transparente (preferible)

### Notas:
- El logo se usa en las siguientes pantallas:
  - `LoginScreen` - Logo de marca de agua (tamaño: 180)
  - `ProfileScreen` - Logo principal (tamaño: 120)
  - `HomeScreen` - Logo principal (tamaño: 100)

- Si el logo no se encuentra, se mostrará un ícono de respaldo automáticamente.

---

**Una vez que coloques el archivo, ejecuta:**
```bash
flutter pub get
```

Y luego prueba la app:
```bash
flutter run
```
